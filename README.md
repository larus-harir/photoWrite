# FRAME & WORDS

사진과 글로 4:5 캐러셀을 만드는 브라우저 편집기입니다. 회원가입·백엔드·외부 AI API 없이 실행됩니다. 특정 사용자의 게시물, 사진, 글 또는 계정명을 기본 콘텐츠로 포함하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 포트는 5173입니다. Windows PowerShell에서 npm 스크립트 실행이 제한되면 `npm.cmd`를 사용하세요.

```bash
npm ci              # 잠금 파일에 맞춰 재설치
npm run build       # TypeScript 검사와 dist/ 빌드
npm run preview     # 빌드 결과 실행
npm test            # 페이지 분할 단위 테스트
npm run test:e2e    # Chromium에서 전체 기능 검증
```

E2E는 `/usr/bin/chromium`이 있으면 사용합니다. 없으면 `npx playwright install chromium`으로 설치하거나 `CHROMIUM_PATH`를 지정하세요. 테스트는 5173 포트의 기존 개발 서버를 재사용하거나 자동 시작합니다.

## 시작하기

1. 첫 접속 시 빈 작업실이 열립니다. **새 프로젝트**를 누르면 사진·제목·본문·촬영 정보·계정명이 모두 빈 상태로 시작합니다. 예제 생성이나 예시 불러오기 기능은 없습니다.
2. JPG·PNG·WebP 사진을 올립니다. 드래그 앤 드롭을 지원하며 30MB·8천만 픽셀 이하 파일을 받습니다. HEIC는 JPG로 변환해 주세요.
3. 제목·부제·본문을 입력하고, 필요한 경우 번호·연도·장소·카메라·필름·작품 설명·계정명을 추가합니다. 사진은 필수이며 나머지 정보는 필요에 따라 채울 수 있습니다.
4. 표지 → 사진 정보 → 본문 N장이 구성됩니다. 빈 본문은 앞의 두 장만 만듭니다. 본문은 원문과 공백·개행을 보존하며 분량에 따라 문단 우선으로 나뉩니다. 긴 문단은 안전하게 줄 단위로 이어집니다.
5. 원하는 위치에서 **페이지 나누기**를 누르거나, 별도 줄에 `---page---`를 입력하면 강제 분할합니다. 구분자는 PNG에 출력되지 않습니다.
6. **템플릿 & 스타일**에서 레이아웃, 제목·본문/부제 글꼴, 표지 제목·본문 제목·부제 크기, 본문 크기·줄 간격·여백을 조절합니다. 기본 글꼴은 Noto Sans KR이며 **기본 글꼴·크기로 복원**할 수 있습니다.
7. 썸네일로 페이지를 선택합니다. 표지는 드래그 또는 슬라이더로 크롭·확대·위치를 조절합니다. 사진 정보 페이지는 원래 비율을 유지합니다. 본문 페이지는 글자 크기·여백·제목 표시·세로 정렬을 별도로 설정할 수 있습니다.
8. 페이지 순서를 화살표로 바꾸고 1080×1350 또는 2160×2700을 선택해 현재 페이지 PNG / 전체 페이지 ZIP을 저장합니다. ZIP 파일명이 현재 페이지 순서를 따릅니다.
9. **작업실로 돌아가기**는 마지막 입력을 저장합니다. 작업실에서 프로젝트를 검색·정렬·복제·삭제하고 다시 열 수 있습니다. 새로고침하면 작업실 목록으로 돌아갑니다.

본문을 편집하면 수동 페이지 순서는 초기화됩니다. 페이지별 스타일은 강제 분할 섹션과 자동 페이지 번호에 연결되므로 앞쪽 글의 분량을 크게 바꾸면 같은 번호의 새 페이지에 적용될 수 있습니다. **본문 → 스타일 → 최종 순서** 순으로 작업하는 것을 권장합니다.

## 화면과 템플릿

입력 글자 15~16px, 안내 글자 12~14px로 표시합니다. 데스크톱 미리보기 기본 너비는 520~580px입니다. 큰 미리보기는 중앙 영역을 스크롤하고, 고정 배율 도구로 20~200%를 조절하거나 **화면에 맞춤**을 사용하세요. 배율 숫자를 누르면 100%로 돌아갑니다. 오른쪽 위 확대 아이콘은 패널을 접어 넓게 보는 모드입니다.

- **Original Archive:** 전체 사진 표지, 흰 여백 사진 페이지, 차콜 본문. 하단 그라디언트는 0%로 끌 수 있습니다.
- **Editorial Journal:** 아이보리 종이와 가는 구분선, 문예지 같은 편집 위계.
- **Film Archive:** 인화지 여백과 큰 사진 창, 번호·촬영 정보 중심의 기록형 레이아웃. 먼지·그레인 효과를 추가하지 않습니다.

## 저장과 사진 처리

- IndexedDB에 여러 프로젝트와 업로드 이미지·글꼴 설정을 독립적으로 저장합니다. 서버 DB는 필요하지 않습니다.
- 사진과 본문을 외부 서버로 전송하지 않습니다. 글꼴도 앱에 포함되어 있습니다.
- 저장은 브라우저와 사이트 주소별입니다. 다른 기기·포트·브라우저와 동기화되지 않으며, 사이트 데이터를 지우면 작업도 삭제됩니다. 원본 사진과 완성 PNG는 별도로 보관하세요.
- 업데이트가 이미 직접 작성한 프로젝트를 자동 삭제하지는 않습니다. 이전 단일 작업도 원문과 업로드 사진을 보존해 프로젝트로 옮깁니다.
- 이전 버전의 내장 예제 파일은 더 이상 포함하지 않습니다. 그 파일을 참조하던 로컬 프로젝트는 텍스트를 보존하고 사진 업로드 상태로 돌아갑니다.
- 필터, 자동 색 보정, 채도·노출 조정, 샤픈·AI 보정을 하지 않습니다. 표지 그라디언트는 조절 가능한 별도 합성 요소입니다.
- PNG는 브라우저 Canvas가 렌더링한 픽셀입니다. 원본 바이트·EXIF·ICC 보존을 의미하지 않으며, 브라우저·디스플레이 색 관리에 따른 차이가 있을 수 있습니다.
- 고해상도 출력이 원본 사진의 디테일을 새로 만들지는 않습니다. 실제 크롭 확대율과 사진 해상도를 기준으로 경고합니다.

## 선별 서체

Google Fonts 공개 배포본을 Fontsource npm 패키지로 선별했습니다. 모두 SIL Open Font License 1.1이며 `public/licenses/`에 원문이 있습니다. 사용자가 배포처 링크를 누를 때만 외부 페이지가 열립니다.

| 서체 | 성격 | 배포처 |
| --- | --- | --- |
| Noto Sans KR | 기본, 명료한 고딕 | https://fonts.google.com/noto/specimen/Noto+Sans+KR |
| Noto Serif KR | 정갈한 명조 | https://fonts.google.com/noto/specimen/Noto+Serif+KR |
| 고운 바탕 | 부드러운 명조 | https://fonts.google.com/specimen/Gowun+Batang |
| IBM Plex Sans KR | 현대적인 편집용 고딕 | https://fonts.google.com/specimen/IBM+Plex+Sans+KR |

선택한 서체 로딩을 기다린 후 실측·분할하며 미리보기와 PNG에 같은 서체·크기를 사용합니다. 본문을 자동 축소하지 않고 다음 페이지로 넘깁니다. 긴 제목은 겹치지 않도록 지정 크기 안에서 맞춥니다.

## 구조와 검증

React + TypeScript + Vite, Canvas 2D, JSZip를 사용합니다.

```text
src/Studio.tsx                작업실과 프로젝트 관리
src/App.tsx                   개별 프로젝트 편집기
src/components/Typography.tsx 글꼴·크기 설정
src/lib/pagination.ts         원문 보존 분할
src/lib/render.ts             템플릿 공통 렌더러
src/lib/media.ts               파일·글꼴 검증
src/lib/export.ts              PNG·ZIP 출력
src/lib/storage.ts             IndexedDB 저장·이전
src/defaults.ts                콘텐츠 없는 프로젝트 기본값
references/DESIGN_NOTES.md     일반적인 템플릿 디자인 설명
tests/fixtures/                테스트 전용 합성 이미지
```

단위 테스트는 한글·영문·한자·이모지·빈 줄·CRLF 보존, 긴 문단, 강제 분할, 빈 본문, 페이지별 스타일과 순서를 검증합니다. 브라우저 테스트는 빈 초기 상태, 프로젝트 독립 저장·복제·삭제·검색, 기존 저장 데이터 이전, 서체별 PNG 픽셀 일치, 업로드·크롭·템플릿 전환, 두 출력 해상도와 ZIP 순서, 모바일 배치와 오류 처리를 검증합니다. 개인 콘텐츠 대신 테스트용 문장과 직접 생성한 합성 이미지를 사용합니다.

여러 사진, 기기 간 동기화, 프로젝트 백업·가져오기, 자유 배치 텍스트 박스, 임의 페이지 삭제, 순서 드래그는 후속 범위입니다.
