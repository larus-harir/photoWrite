# 템플릿 디자인 원칙

앱은 특정 사용자의 사진·글·게시물을 포함하지 않습니다. 작업실은 빈 상태로 시작하며 템플릿은 사용자가 입력한 콘텐츠에 적용되는 레이아웃만 제공합니다.

## 공통

모든 페이지는 정확히 4:5입니다. 표지, 원래 비율을 보존하는 사진 정보 페이지, 자동 분할 본문으로 이어집니다. 원본 사진에 필터나 자동 보정을 적용하지 않습니다. 제목·본문의 크기와 글꼴은 사용자 설정을 따르며, 긴 본문은 글자를 줄이지 않고 다음 페이지로 넘깁니다.

## Original Archive

사진 전체를 사용하는 표지, 넓은 흰 여백의 사진 페이지, 거의 검은 차콜(#091114) 본문을 연결합니다. 선택적으로 표시하는 번호와 계정명은 사용자가 입력한 값만 사용합니다. 표지 하단 그라디언트는 사용자가 조절하거나 해제할 수 있습니다.

## Editorial Journal

아이보리(#f2efe7), 차분한 녹회색 글자, 가는 구분선과 넉넉한 여백으로 구성합니다. 명조를 선택하면 문예지 분위기로, 고딕을 선택하면 현대적인 편집물로 사용할 수 있습니다.

## Film Archive

인화지 색(#e9e5db), 큰 사진 창과 절제된 기록용 라벨을 사용합니다. 먼지·그레인·색 필터를 추가하지 않습니다.

## 편집 UI

입력 내용과 결과물을 구분하기 위해 종이색·올리브 컨트롤과 도트 작업판을 사용합니다. 빈 콘텐츠는 안내 문구로 설명하고, 특정 사람의 사진·계정·글로 채우지 않습니다. 새 프로젝트의 기본 서체는 Noto Sans KR이며 나머지 선별 서체도 공개 라이선스 배포본을 자체 제공합니다.
